# SBO 베이스볼

SBO(세구 베이스볼 온라인) 4팀으로 리그를 치르는 캐주얼 아케이드 야구 팬게임이에요.

## 실행
- `index.html` 한 파일에 게임 코드, 선수 데이터, 초상화, 공지가 모두 들어 있어요.
- 웹 서버 없이 파일을 바로 열어도 돼요. 글꼴만 인터넷에서 불러와요.
- Cloudflare Pages에서는 빌드 명령 없이 저장소 루트(`/`)를 그대로 배포하면 돼요.

## 데이터
- 선수·스태프·스킬 데이터와 공지는 파일을 만든 시점의 내용으로 고정돼 있어요.
- 데이터를 바꾸려면 원본 게임에서 "게임 다운로드"로 새 `index.html`을 받아 이 파일을 교체해요.

## 게임 모드
- **리그 모드:** 네 팀이 홈·원정 두 번씩 경기하고, 정규 6라운드 상위 두 팀이 결승을 치러요.
- **연습 경기:** 두 팀을 골라 한 경기를 치러요. 3·5·7·9이닝 중에서 고를 수 있어요.
- **팀 정보:** 감독·코치와 선수 명단, 능력치, 스킬을 볼 수 있어요.

## 안내
- 게임에 나오는 캐릭터, 이름, 이미지 등 관련 권리는 모두 SOOP 스트리머 분들과 각 원작자에게 있어요.
- SBO 로고와 팀 로고를 포함한 행사의 상표·저작물에 대한 권리는 주최자 고세구님을 비롯한 스트리머 분들께 있어요.
- 제작자는 어떠한 권리도 주장하지 않아요.
- 비영리 목적으로만 만들고 공개했으며, 이 게임으로 수익을 얻지 않아요.
- 게임의 코드, 이미지 등 리소스를 무단으로 복제·수정·재배포하는 것은 금지돼요.
- 능력치와 스킬은 경기 내용을 모티브로 한 가상의 값이고, 객관적 지표를 그대로 반영한 것이 아니에요.
